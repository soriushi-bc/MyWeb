結算：只有第 1/2 名能拿到生命值（下注×賠率×1.00 / 0.50）；若你押到最後一名，額外倒扣 10（生命值）。
死亡：HP ≤ 0 死亡並可重開。
增益區：加速更強。　 泥沼/反增益：阻力更大、速度衰減更劇烈。　 煞車帶：瞬間降速更明顯。　 黏滯區：反彈變鈍、動能更容易被吃掉。　 彈跳區：反彈更有力。　 重力帶：經過時重力加大。
風場：強風沿風向拖拽。　 黑洞：釘住 2 秒，結束後會被彈開。　 白洞：傳送到周圍更遠距離。
